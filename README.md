# Repair Shop Nightmare — The Loop Game

A funny, responsive, browser-based arcade game where you compete against CHIP, a sarcastic computer technician. Diagnose ridiculous phone-repair tickets, score points, and survive three increasingly chaotic levels.

## Play

Open [the game](https://hichandu810chandupathak-beep.github.io/Crash-game/) after enabling GitHub Pages for the repository (Settings → Pages → Deploy from a branch → `main` / `/(root)`). You can also open `index.html` locally in a modern browser.

## How it works

- **Level 1 — Warm-up:** five repair tickets, a relaxed timer, and three possible fixes.
- **Level 2 — Glitch Shift:** six tickets, a shorter timer, four choices, and surprise visual glitches.
- **Level 3 — Chaos Mode:** seven tickets, the fastest timer, five choices, and unpredictable screen/button tricks.
- Correct repairs earn you **10 points**. Wrong answers or timeouts give CHIP **5 points**.
- CHIP reacts with dynamic jokes, win/loss commentary, and increasingly ridiculous interruptions.
- Optional synthesized sound effects; no audio files or external game engine required.

## Controls

Tap or click the repair action that solves the customer's problem. Use **Need a hint?** if you get stuck. Start a new shift or reset at any time. The game is designed for mobile and desktop screens.

## Files

- `index.html` — semantic game layout and accessible controls.
- `style.css` — responsive visual design, animations, and reduced-motion support.
- `script.js` — level progression, scoring, timer, computer personality, and surprise events.

## Technology

Vanilla HTML5, CSS3, and JavaScript. No framework, build step, account, real-money betting, or backend is required.
