# The Ultimate Troll & Laugh Loop 🤣

A fresh, universally relatable, mobile-friendly comedy arcade game. Play against a cheeky computer through three rounds of everyday nonsense. No tech knowledge, accounts, backend, or real-money mechanics required.

## Play

Open `index.html` in a modern browser. To publish with GitHub Pages, open repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## The three levels

1. **Monday Morning Resistance** — drag the alarm clock away (or tap it) while the game serves up sleepy excuses.
2. **The Relative Interrogation** — answer nosy relatives with quick, funny comebacks before the timer expires.
3. **Brain Cell Meltdown** — rapid-fire absurd scenarios, visual twists, and buttons that refuse to behave.

## Scoring and controls

- Successful moves earn **10 laugh points**.
- Misses and timeouts give the computer **5 chaos points**.
- Use the hint button when you need a nudge.
- Sound is optional and synthesized by the browser; no sound files are downloaded.
- Start, reset, and play again whenever you like.

## Files

- `index.html` — accessible game structure and screens.
- `style.css` — responsive layout, colourful arcade styling, and motion effects.
- `script.js` — round progression, touch/mouse interaction, scoring, timer, computer commentary, and chaos events.

## Technology

Vanilla HTML5, CSS3, and JavaScript. No build tools or dependencies required. Google Fonts are an optional visual enhancement; system fonts are used as fallbacks.
